# Project Overview — MPG

**What:** A minimalist, dark-mode directory that lists Malaysian payment
gateways in a comparison table (fees, settlement, channels, features), with a
detail page per gateway and a side-by-side compare tool. Visual style follows
openrouter.ai/models.

**Who it's for:** Malaysian businesses / developers choosing a payment gateway,
who want to compare fees (FPX, card, e-wallet, DuitNow QR, BNPL) at a glance.

**Goals / success:**
- Accurate, sourced fee data (each gateway cites its source + verified date).
- Fast, clean UX: sort / filter / search the table; compare up to 4 side by side.
- Easy to extend: add a provider by dropping one markdown file.

**Scope now:** 34 gateways (gateways + BNPL). Static site, free & independent
(not affiliated with any provider). Auth (sign up / accounts) added for upcoming
favourites + gateway-submission features.

**Live:** https://mpg-1hw.pages.dev · **Repo:** github.com/afu-it/mpg (private)
