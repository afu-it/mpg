BetterPay (Pay Direct Technology Sdn Bhd) ialah gateway Malaysia yang menonjolkan
**kelajuan duit masuk**: FPX (bayar terus dari akaun bank online) masuk T+1 (sehari
bekerja selepas jualan) untuk pelan biasa, dan pelan Pro mengiklankan **duit masuk
serta-merta melalui pindahan bank**, lebih cepat daripada kebiasaan industri (T+1 hingga T+2). Ia mendakwa memproses lebih RM9 bilion setahun melalui 150+ saluran
bayaran dengan satu API sahaja.

Senarai kadarnya disiarkan lengkap: FPX rata **RM1.00** (B2C), kad tempatan
**1.9%**, e-wallet utama Malaysia **1.5%**, DuitNow QR dari 1.0 hingga 1.2%, dan BNPL
(beli sekarang bayar kemudian) melalui Atome dan GrabPayLater. Pelannya berbeza ikut fee setup sekali bayar (dari Starter RM0 untuk FPX sahaja hingga Pro
RM500), dan tiada fee bulanan untuk mana-mana pelan.

Selain API, ia ada link bayaran, e-invois dengan peringatan, terminal maya, caj kad
berulang serta debit terus e-Mandate, dan plugin (tambahan siap pasang) untuk
kebanyakan platform kedai online utama (Shopify ada caj tambahan 0.5%). Sistem API-nya
dikongsi dengan QlicknPay, guna Merchant ID + API key untuk pengesahan dan callback
(notifikasi balik) yang ditandatangani.
